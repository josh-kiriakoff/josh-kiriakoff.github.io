rundll32 invoked without a .dll/.cpl argument

ATT&CK · T1218.011 (Rundll32) Tactic · Defense Evasion
Hypothesis. On a healthy Windows host, every legitimate rundll32.exe invocation references a target module (.dll, .cpl, or .ocx) somewhere on its command line. Invocations missing that target are anomalous and worth surfacing for triage.

context

rundll32.exe is a signed Microsoft binary whose canonical job is to call an exported function from a DLL — the documented invocation shape is rundll32.exe <module>.dll,<EntryPoint> <args>. Adversaries abuse it as a LOLBIN in two recurring shapes:

  • Masquerading a foreign process as rundll32 for living-off-the-land cover.
  • Launching it with no recognisable module argument so a child / injected payload can take over.

The hypothesis above is a deliberately narrow cut at the second shape. Hunting for the first shape (masquerading) is a separate exercise.

hunt

ES|QL against the canonical Huntress Process Insights schema. Sorted ascending so the long tail surfaces first — anomalies live in the rare end of the distribution, not the common end. TO_LOWER() on process.name is a defensive guard against case-inconsistent telemetry. 

// hypothesis: rundll32.exe with no .dll/.cpl/.ocx target on the command line.
// schema:     Huntress Process Insights — process_events

FROM logs-edr-process_events
| WHERE TO_LOWER(process.name) == "rundll32.exe"
| WHERE NOT TO_LOWER(process.command_line) LIKE "*.dll*"
| WHERE NOT TO_LOWER(process.command_line) LIKE "*.cpl*"
| WHERE NOT TO_LOWER(process.command_line) LIKE "*.ocx*"
| STATS hits = COUNT(*)
        BY host.name, process.parent.name, process.command_line
| SORT hits ASC
| LIMIT 100

findings & discriminators

Across a representative fleet the result-set splits roughly into three buckets, which the resulting rule needs to either embrace or reject:

  • Empty / near-empty command line. rundll32.exe with no arguments. Usually a child process whose parent is doing something interesting — check ancestry up three levels.
  • Office / scripting parents. winword.exe, excel.exe, mshta.exe, wscript.exe, powershell.exe — these parents materially raise the prior. Promote any hit to a detection.
  • Signed launcher parents. msiexec.exe, OEM updaters, AV subprocesses — these can produce rundll32 children without DLL arguments and are the principal noise source. The rule's discriminator list excludes them by parent name.

resulting sigma rule

Rule. rundll32 executed with no .dll / .cpl / .ocx on its command line, and whose parent is not on the small allow-list of signed launchers that legitimately do this. Severity: medium. 
title:       Rundll32 Invoked Without A Module Argument
id:          b76d1cd8-15e3-4d50-a9fc-3fa5e1aef496
status:      experimental
description: Detects rundll32.exe whose command line contains no
             recognisable module target (.dll, .cpl, .ocx). Adversaries
             use this shape as a LOLBIN cover for foreign-managed child
             processes and injection.
references:
  - https://attack.mitre.org/techniques/T1218/011/
  - https://lolbas-project.github.io/lolbas/Binaries/Rundll32/
author:      Josh Kiriakoff
date:        2026/05/25
tags:
  - attack.defense_evasion
  - attack.t1218.011
logsource:
  category: process_creation
  product:  windows
detection:
  selection_image:
    Image|endswith: '\rundll32.exe'
  filter_module:
    CommandLine|contains:
      - '.dll'
      - '.cpl'
      - '.ocx'
  filter_signed_launchers:
    # Starter list. Extend with OEM updaters and AV subprocesses
    # specific to the fleet as FPs are observed.
    ParentImage|endswith:
      - '\msiexec.exe'
      - '\TrustedInstaller.exe'
      - '\MsMpEng.exe'           # Microsoft Defender Antimalware
      - '\NisSrv.exe'            # Defender Network Inspection
      - '\setup.exe'             # generic installer
      - '\update.exe'            # generic updater
      - '\updater.exe'
  condition: selection_image and not filter_module and not filter_signed_launchers
falsepositives:
  - Signed third-party installers / OEM updaters not yet on the allow-list.
  - Niche enterprise software wrapping rundll32 in an opaque way.
level:       medium

false positives, scoping notes

Known FPs. Signed third-party installers occasionally invoke rundll32 with a stub command line during install / uninstall. These are easily allow-listed by parent image. Treat any new FP as a small extension to filter_signed_launchers rather than a relaxation of filter_module.
