Komari monitoring agent used as a C2 implant

ATT&CK · T1219 (Remote Access Software) ATT&CK · T1071.001 (Web Protocols) Tactic · Command and Control
Hypothesis. Komari is an open-source monitoring agent with a reverse shell built into the default install, which makes it an all-in-one C2 implant an operator can deploy in one step. The agent binary, its install and API markers, and the agent parenting a shell are each worth surfacing.

context

The reverse shell ships in the box. That is what turns a monitoring tool into an implant, because an operator gets host telemetry and a command channel from the same install with nothing extra to drop. The distinctive markers are the komari-agent name, the komari-monitor GitHub install path, the report and uploadBasicInfo API endpoints, and the --ignore-unsafe-cert flag that accepts a self-signed C2 certificate.

The on-host giveaway is lineage. The agent spawning cmd or powershell is an operator running commands through it, not passive monitoring. This grew out of Huntress research into the tool, linked below.

hunt

Match the Komari agent by name, by its C2 and install markers, or parenting a shell.

// hypothesis: Komari agent execution or operator command lineage.
// schema:     Huntress Process Insights - process_events

FROM logs-edr-process_events
| WHERE TO_LOWER(process.name) == "komari-agent.exe"
     OR TO_LOWER(process.command_line) LIKE "*ignore-unsafe-cert*"
     OR TO_LOWER(process.command_line) LIKE "*uploadbasicinfo*"
     OR TO_LOWER(process.command_line) LIKE "*komari-monitor/komari-agent*"
| WHERE process.parent.name IS NOT NULL
| KEEP host.name, process.parent.name, process.name, process.command_line
| SORT @timestamp DESC
| LIMIT 100

findings & discriminators

  • Confirm intent, not just presence. Komari is a real tool. An install from a raw GitHub URL onto a server reached over RDP is the malicious shape, not a planned deployment.
  • Lineage is the strongest hit. The agent parenting a shell is an operator at the keyboard, which the passive install never produces.
