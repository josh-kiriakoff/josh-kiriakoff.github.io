system DLL name loaded from a non-system directory

ATT&CK · T1574.002 (DLL Side-Loading) ATT&CK · T1036.005 (Match Legitimate Name) Tactic · Defense Evasion Tactic · Persistence
Hypothesis. Side-loading kits plant a look-alike copy of a frequently imported system DLL, such as version.dll or dbghelp.dll, next to a signed executable so the planted copy resolves first. A system DLL name loaded from outside the system and vendor directories surfaces that swap regardless of the host binary.

context

This rule watches the module, not the process. Where the previous rule keys on an unsigned module under a signed loader, this one keys on the name. A file called wininet.dll loading from a Downloads folder is a planted copy standing in for the real one in System32.

Keying on the name catches the swap even when the attacker signs the planted DLL, which is why it sits alongside the unsigned-module rule rather than inside it. The allow-list is the real system and vendor paths.

hunt

Match a common system DLL name loading from outside system and vendor paths.

// hypothesis: a system DLL name loading from a non-system directory.

FROM logs-edr-library_events
| WHERE ENDS_WITH(TO_LOWER(dll.path), "\\version.dll")
     OR ENDS_WITH(TO_LOWER(dll.path), "\\wininet.dll")
     OR ENDS_WITH(TO_LOWER(dll.path), "\\dbghelp.dll")
| WHERE NOT TO_LOWER(dll.path) LIKE "*\\windows\\system32\\*"
     AND NOT TO_LOWER(dll.path) LIKE "*\\windows\\winsxs\\*"
     AND NOT TO_LOWER(dll.path) LIKE "*\\program files*"
| KEEP host.name, process.executable, dll.path
| SORT @timestamp DESC
| LIMIT 100

findings & discriminators

  • The name plus the path is the swap. A system DLL name resolving from a user or temp directory is the planted copy winning the search order.
  • Confirm the publisher. Portable apps sometimes ship private copies of these DLLs, so a copy beside a downloaded or temp-staged executable is the stronger signal.

resulting sigma rule

Rule. Detects a module carrying the file name of a common Windows system DLL being loaded from outside the system and vendor directories. Rated high.

  selection_sysdll:
    ImageLoaded|endswith:

      - '\dbghelp.dll'

      - '\winhttp.dll'
      - '\secur32.dll'
      - '\userenv.dll'

      - '\cryptsp.dll'
      - '\wtsapi32.dll'
      - '\dwmapi.dll'
      - '\propsys.dll'
      - '\textinputframework.dll'

    ImageLoaded|contains:
      - '\Windows\System32\'
      - '\Windows\SysWOW64\'
      - '\Windows\WinSxS\'
      - '\Program Files\'
      - '\Program Files (x86)\'
  condition: selection_sysdll and not filter_system_paths
