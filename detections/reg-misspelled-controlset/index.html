reg.exe writing to a misspelled ControlSet hive path

ATT&CK · T1112 (Modify Registry) Tactic · Defense Evasion Tactic · Persistence
Hypothesis. Windows reads its live configuration from CurrentControlSet and the numbered ControlSet001 to ControlSet003 hives, and nowhere else. A reg add against a misspelled variant such as CurentControlSet writes a dead key that nothing will ever read, so any such write is a fat-fingered administrator or, far more often, a typo baked into an attacker's copy-paste hardening script.

context

reg.exe is a signed Microsoft binary, so the interesting signal is never the tool. It is the argument. Hands-on operators carry a block of registry commands from host to host to loosen a machine before they settle in, turning on RDP, dropping fDenyTSConnections, relaxing a policy. When that block contains a misspelling, the misspelling travels with it verbatim.

That makes the typo a better pivot than any correctly spelled command beside it. The valid commands blend into normal administration. The dead key does not. I pulled this apart in a case where the only tooling on a domain controller was Windows itself, linked below.

hunt

Match reg.exe whose command line carries one of the known misspellings. The list below is a sample, the rule carries the full set.

// hypothesis: reg.exe writing to a misspelled *ControlSet* path.
// schema:     Huntress Process Insights - process_events

FROM logs-edr-process_events
| WHERE TO_LOWER(process.name) == "reg.exe"
| WHERE TO_LOWER(process.command_line) LIKE "*curentcontrolset*"
     OR TO_LOWER(process.command_line) LIKE "*currrentcontrolset*"
     OR TO_LOWER(process.command_line) LIKE "*currentcontolset*"
| KEEP host.name, user.name, process.parent.name, process.command_line
| SORT @timestamp DESC
| LIMIT 100

findings & discriminators

  • Zero legitimate producers. No installer or admin tool writes to a misspelled hive on purpose. Read every hit as operator error inside a script that meant to harden the host.
  • The parent tells you the rest. A misspelled reg add parented by a remote session host or a shell dropped mid-intrusion is the shape worth chasing, not a lone typo in an interactive prompt.
