silent MSI install of a temp ~vrf installer

ATT&CK · T1218.007 (Msiexec) Tactic · Defense Evasion Tactic · Execution
Hypothesis. A stealer or loader chain that stages a follow-on MSI into the user temp directory names it something like ~vrf<GetTickCount>.msi and installs it with no UI. A msiexec install that is silent, points at a ~vrf file, and runs from a user path is worth surfacing on its own.

context

msiexec.exe is signed and runs constantly, so a bare install is nothing. The tell is the combination. The ~vrf prefix with a numeric tail is the output of GetTickCount, unique per run, and the file lands in temp rather than a real install location.

These MSIs frequently carry a PowerShell CustomAction that runs iex against a remote URL, which turns the installer into a reinfection trigger rather than a one-off. I met this pattern in the ClickFix chain linked below, where the delivery did the work and every stage after it leaned on signed, built-in tools.

hunt

Match msiexec installing silently from a ~vrf temp file.

// hypothesis: silent msiexec install of a ~vrf temp MSI.
// schema:     Huntress Process Insights - process_events

FROM logs-edr-process_events
| WHERE TO_LOWER(process.name) == "msiexec.exe"
| WHERE TO_LOWER(process.command_line) LIKE "*~vrf*"
     AND TO_LOWER(process.command_line) LIKE "*.msi*"
| WHERE TO_LOWER(process.command_line) LIKE "*/qn*"
     OR TO_LOWER(process.command_line) LIKE "*/quiet*"
| KEEP host.name, process.parent.name, process.command_line
| SORT @timestamp DESC
| LIMIT 100

findings & discriminators

  • The three parts together are the signal. Silent, ~vrf, and a temp path each occur alone in benign installs. Requiring all three drops the noise to near nothing.
  • Read the parent and the installing account. A browser child or a script host parenting this install is the reinfection shape. A vendor updater doing it is the rare false positive.

resulting sigma rule

Rule. Detects msiexec.exe silently installing (/qn or /quiet) an MSI whose file name carries the "~vrf" prefix. Rated high.
