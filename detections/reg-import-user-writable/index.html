reg.exe importing a .reg file from a user-writable directory

ATT&CK · T1112 (Modify Registry) ATT&CK · T1547.001 (Run Keys) Tactic · Persistence
Hypothesis. A single reg import applies an arbitrary number of keys in one action. Point it at a .reg file in a user-writable directory and an operator can plant persistence, evasion toggles, and COM hijacks in one shot, while producing far less per-value telemetry than editing each key by hand.

context

The bulk import is the point. Editing the registry key by key leaves a trail an analyst can follow value by value. Importing a prepared .reg file collapses all of that into one process event, and the interesting content lives in a file rather than on the command line.

The location narrows it fast. A legitimate import usually restores a saved backup from a known path. An import from AppData, user temp, Downloads, Public, or ProgramData, in the middle of other activity, is the shape that matters.

hunt

Match reg.exe import where the path sits in a user-writable directory.

// hypothesis: reg.exe import of a .reg file from a user-writable path.
// schema:     Huntress Process Insights - process_events

FROM logs-edr-process_events
| WHERE TO_LOWER(process.name) == "reg.exe"
| WHERE TO_LOWER(process.command_line) LIKE "* import *"
| WHERE TO_LOWER(process.command_line) LIKE "*\\appdata\\*"
     OR TO_LOWER(process.command_line) LIKE "*\\temp\\*"
     OR TO_LOWER(process.command_line) LIKE "*\\downloads\\*"
| KEEP host.name, user.name, process.parent.name, process.command_line
| SORT @timestamp DESC
| LIMIT 100

findings & discriminators

  • The path is the discriminator. System-managed imports come from system paths. A user-writable source directory is what separates an attacker's staged file from a restore.
  • Pull the .reg contents. The command line only shows the import. The keys it applied are in the file, so recover it before you rule the hit in or out.

resulting sigma rule

Rule. Detects reg.exe performing an "import" of a .reg file located in a user-writable directory (AppData, user Temp, Windows Temp, Downloads, Public, or ProgramData). Rated medium.

detection:
  selection_reg:
    - Image|endswith: '\reg.exe'

  selection_import:
    CommandLine|contains: ' import '
  selection_userpath:
    CommandLine|contains:
      - '\AppData\'
      - '\Users\Public\'
      - '\Windows\Temp\'
      - '\Downloads\'
      - '\ProgramData\'
      - '\Temp\'
  condition: selection_reg and selection_import and selection_userpath
fields:
  - CommandLine
  - ParentImage
  - User
falsepositives:
  - An administrator restoring a saved registry backup from a temp folder. Confirm the .reg contents and the surrounding activity.

false positives, scoping notes

Known FPs. An administrator restoring a saved registry backup from a temp folder will fire this. Confirm the file contents and the surrounding session.
