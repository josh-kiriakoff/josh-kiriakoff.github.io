A note on what is in here. I cannot publish the detections I write for my employer, or any rule I have worked on as part of that job, so none of them appear on this page. Everything below is separate work. These are generic, host-focused detections I have built from public threat intelligence, my own research, and tradecraft I have seen described or run into myself, and they stand apart from my employer's coverage. Where a rule grew out of one of my own writeups I have linked it.

Each entry is one artefact, written end-to-end as a single document: a falsifiable hypothesis, the ES|QL hunt that expresses it, the findings and discriminators that separate signal from noise, and the resulting Sigma rule.

The structure each writeup follows:

  1. Hypothesis — one sentence, falsifiable.
  2. Context — TTPs, MITRE ATT&CK technique IDs, why this matters.
  3. Hunt — runnable ES|QL against the canonical telemetry schema, over process, module-load, or Windows event data as the rule needs.
  4. Findings & discriminators — fields that separate signal from noise.
  5. Sigma rule — the detector the hunt produced.
  6. False positives — known FPs, scoping notes.
  7. References.
